# やらないこと（医療広告ガイドライン・ステマ規制・AI向け不正行為）

AIは矛盾や誇張を見つけると推薦を避ける。法令順守がそのまま LLMO に効く。

## 医療広告ガイドライン（医療法）で禁止

| 禁止 | 具体例 | 代わりにできること |
|---|---|---|
| 比較優良 | 「大森でNo.1」「他院より安い」「最高の技術」 | 事実（駅徒歩1分、土日19時まで、無料相談）を書く |
| 誇大 | 「必ず治る」「痛くない矯正」「最新・最先端」 | 「痛みは数日でおさまることが多い」など幅のある事実 |
| 体験談 | 患者の感想、口コミの転載、Googleレビューのサイト掲載 | Googleレビューは Google 上に置いたまま（第三者投稿は規制対象外） |
| ビフォーアフター | 条件を満たさない症例写真 | 掲載するなら 治療内容・費用・期間・回数・リスク副作用 を写真ごとに併記 |
| 公序良俗違反・虚偽 | 存在しない資格、誤った所属 | 学会・資格は正式名称と年次 |
| 広告可能事項以外 | 「審美歯科」「インプラント科」などの科名表示 | 「矯正歯科」を使う |

## 限定解除（ウェブサイトで詳しい情報を書くための4要件）

1. 患者が自ら求めて閲覧する情報（ウェブサイト等）であること
2. 問い合わせ先（電話・メール等）を明示
3. 自由診療の 治療内容・費用（範囲可）・期間・回数 を記載
4. 自由診療の 主なリスク・副作用 を記載

→ `02-website/page-checklist.md` B節でページごとに確認。

## ステマ規制（景品表示法、2023年10月〜）

- レビュー投稿の対価（割引・プレゼント）を提供しない。
- 星の数や文言を指定した依頼をしない。「よろしければGoogleでご感想をお寄せください」までにとどめる。
- スタッフ・関係者によるレビュー投稿をしない。

## AI向けに逆効果になる行為

- 隠しテキスト、白文字、AIだけに見せる別コンテンツ（クローキング）
- 事実と異なる構造化データ（実際と違う診療時間・料金）
- 大量の低品質記事の自動生成（Brave / Google の品質評価で全体の評価が下がる）
- 他院名を出した比較記事（比較優良に該当しうる。競合比較はAIに任せ、自院は事実を揃える）
