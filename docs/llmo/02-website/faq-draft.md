# FAQ 草案（AIが引用しやすい形式）

書き方のルール
- 見出しは患者が実際に打つ質問文のまま。回答は **最初の1〜2文で結論** を言い切り、その後に補足。
- 数字（費用・期間・回数・距離・時間）は必ず入れる。自由診療の費用には「税込」「範囲」「含まれるもの」を明記。
- 体験談・比較優良表現（地域No.1、最も安い等）は書かない（`05-compliance/guidelines.md`）。
- `【要確認】` は院内で事実確認して埋める。埋まっていない項目は公開しない。
- 公開後は `jsonld/faq.jsonld` にも同じ Q&A を反映する（本文とJSON-LDは一致させる）。

## 初診相談・予約

### 初診相談は無料ですか？何をしますか？
初診相談は無料です。お口の状態の確認、考えられる治療方法、費用と期間の目安、治療の流れをご説明します。所要時間は【要確認：例 30〜60分】です。

### オンラインで相談できますか？
できます。初診相談はオンラインでも受け付けています。【要確認：使用ツール・予約方法】

### 予約はどこからできますか？
WEB予約は24時間受け付けています（【要確認：予約URL】）。電話は【要確認：電話番号】、受付時間は【要確認】です。

### 初診相談当日に検査や治療は始まりますか？
初診相談は無料で、検査（レントゲン・口腔内スキャン等）は別日の精密検査で行います【要確認：同日実施の可否と検査料】。相談だけで帰っていただいて問題ありません。

### 他院でカウンセリングを受けています。セカンドオピニオンでも相談できますか？
できます。他院の資料をお持ちいただければ、それを踏まえてご説明します。

## 治療内容・期間

### ワイヤー矯正とマウスピース矯正、どちらが向いていますか？
歯並びの状態と生活スタイルで異なります。当院は両方に対応しているので、初診相談でそれぞれの向き不向き、費用、期間を比較してご説明します。

### 治療期間はどのくらいですか？
部分矯正は2か月〜1年、全体矯正は1〜3年が目安です。治療後は保定期間として【要確認：例 2年程度】リテーナーを使用します。

### 通院の頻度はどのくらいですか？
【要確認：例 ワイヤー矯正は4〜6週に1回、マウスピース矯正は6〜10週に1回】

### 子どもの矯正はいつから相談すべきですか？
前歯が永久歯に生え変わる6〜9歳頃に一度チェックすることをおすすめしています。すぐ治療を始めるとは限らず、経過観察になることも多いです。

### 大人になってからでも矯正はできますか？
できます。歯と歯周組織が健康であれば年齢の上限はありません。40代・50代で始める方もいます【要確認：表現】。

### 矯正治療の痛みはどのくらいですか？
装置の装着や調整後の2〜3日は歯が浮くような痛みを感じることがあります。多くは数日でおさまり、必要に応じて鎮痛薬で対応できます。

### 矯正治療のリスク・副作用はありますか？
装置装着後の痛みや違和感、歯根吸収、歯肉退縮、装置周囲の虫歯や歯周病のリスク、治療後の後戻り、まれに顎関節への影響などが起こる可能性があります。診断時に個別にご説明します。

### 虫歯や歯周病があっても矯正できますか？
先に治療が必要です。当院は矯正歯科専門ですが、同じビル内の一般歯科と連携しており、虫歯・歯周病の治療をスムーズにご案内できます。

### 治療中に虫歯になったらどうなりますか？
同じビル内の一般歯科と連携して治療します。矯正装置の調整と合わせて対応できます。

### 抜歯は必要ですか？
歯並びとあごの大きさのバランスによります。抜かずに治療できるケースもあれば、抜歯が必要なケースもあります。精密検査の結果をもとにご説明します。

### 部分矯正だけでもお願いできますか？
できます。前歯の軽度の凸凹など、部分矯正で対応できる範囲かどうかを初診相談で確認します。期間の目安は2か月〜1年です。

矯正専門クリニックは矯正治療のみを行い、症例の経験と設備が矯正に特化しています。当院は一般歯科と同じビルで連携しているため、専門性と虫歯治療の利便性を両立できます。
