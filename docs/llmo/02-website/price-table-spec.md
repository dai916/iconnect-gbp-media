# 料金表ページ（/price）の作り直し仕様

現状の料金表は、左の列（治療名）と右の列（金額）を別々の div で並べ、見た目だけで揃えている。
人には表に見えるが、機械（検索AI・Google）には「治療名の一覧」と「金額の一覧」が別々に見え、対応づけができない。
2026-09-30 の実査では、HTML の順序どおりに読むと金額が1行ずれて読める状態だった。

## 依頼内容

1. 料金表を **本物の表（`<table>`）** に作り直し、1行に「治療名」「費用」「含まれるもの」を入れる。
   `<th scope="row">` に治療名、`<td>` に費用と含まれるもの。見た目は現状どおりでよい。
   人が見る表に「別途かかるもの」の列は入れない。区分（小児矯正・成人矯正・調整料）は列ではなく左端の見出しセルで表す。費用は「10,000円（税込 11,000円）」の書き方で統一する。
2. 同ページに `jsonld/price-offers.jsonld` を `<script type="application/ld+json">` で埋め込む（金額付きの Offer）。
3. 「分割払い（最長XXX回まで）」という仮の文字が公開されているので、「最長120回まで」に直す。
4. ~~「遠隔診療加算」の金額を 100,000円（税込 110,000円）に修正する~~ **2026-10-26 本番反映済み**。
5. ブログ記事 `/archives/1803` に古い金額（マウスピース型全体矯正 990,000円 等）が残っているので、この料金表に合わせて更新する。
