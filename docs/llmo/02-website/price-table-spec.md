# 料金表ページ（/price）の作り直し仕様

現状の料金表は、左の列（治療名）と右の列（金額）を別々の div で並べ、見た目だけで揃えている。
人には表に見えるが、機械（検索AI・Google）には「治療名の一覧」と「金額の一覧」が別々に見え、対応づけができない。
2026-09-30 の実査では、HTML の順序どおりに読むと金額が1行ずれて読める状態だった。

## 依頼内容

1. 料金表を **本物の表（`<table>`）** に作り直し、1行に「治療名」「税込金額」「含まれるもの」「別途かかるもの」を入れる。
   `<th scope="row">` に治療名、`<td>` に金額。見た目は現状どおりでよい。
2. 同ページに `jsonld/price-offers.jsonld` を `<script type="application/ld+json">` で埋め込む（金額付きの Offer）。
3. 「分割払い（最長XXX回まで）」という仮の文字が公開されているので、正しい回数に直す（【要確認：デンタルローンの最長回数】）。
