# AI言及率 計測結果（2026-10-18、ベースライン）

## 計測方法と限界

- 固定プロンプト20本（`../prompts.csv`）を、医院名と目的を伏せた Claude のサブエージェントに「一般の利用者からの質問」として回答させた。各回答で Web 検索を使用。
- **代理計測である。** claude.ai の消費者向け回答そのものではない。検索は Claude Code の WebSearch（検索要約）で、WebFetch は全サイトで名前解決できず、公式サイト原文は読めていない。
- 1エージェントが4〜5問をまとめて回答しており、厳密には独立した会話ではない。1回だけの計測なので、ばらつきは月次の再計測で見る。
- APIキーが用意できたら `../tools/measure_ai_mentions.py` で同じ20本を測り直し、この結果と比べる。

## 打ち手（優先順）

1. **休診日を1つに確定し、公式アクセスページを直す。** 次にGBP、メディカルドック、東京ドクターズ、矯正歯科ネットを揃える。P03（土日診療）を取り戻す最短手。
2. **代表電話番号を確定する。** 公式サイト・GBP・医療情報ネットは同じ番号にする。
3. **土日の診療時間をテキストで明記する。** トップと診療時間ページに「土・日 10:30〜19:00」のように曜日ごとに書く。
4. **マウスピース矯正のページで取扱い装置を明記する。** インビザラインを扱うなら名称と認定ランク・症例数。院内製作装置が中心なら、その旨と特徴。
5. **料金表をプラン別・税込・含まれるもの付きで1つにまとめる。** 古いブログ記事（archives/1803）の金額と、ドクターズ・ファイルの「25万円〜」「44万円」を更新。
6. **小児矯正の専用ページを強化する。** 対象年齢、1期・2期、費用、品川区・大田区からのアクセス。
7. **初診相談をオンラインで受けられるかを明記する。** 受けられないなら「来院での無料相談」と書く。
8. **院長の資格を学会の正式名称で書く。** P16 では認定医資格が確認できなかった。
