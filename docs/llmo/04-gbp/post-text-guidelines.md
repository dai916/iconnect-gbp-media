# GBP「最新情報」投稿本文の書き方（AIに読まれる前提）

このリポジトリの `images/` に毎日置いている黒板画像は、Googleマップ上では人が見るが、
AIは **投稿の本文テキスト** を読む。画像の中の文字は読まれない。
本文側の書き方を次のルールに揃える（投稿の仕組みは非公開リポジトリ `iconnect-gbp` 側で変更する）。

## 毎回入れる要素

1. **その日のテーマ**（画像と同じ内容を文章で。1〜3文）
2. **医院の事実を1つ**（下の一覧からローテーション）
3. **行動の一文**（例：「無料初診相談はWEBから24時間ご予約いただけます」）
4. **リンク**（`https://iconnect-ortho.com/contact?src=gbp_post`）

## 「医院の事実」ローテーション一覧

- JR大森駅 東口から徒歩1分（東京都品川区南大井）
- 土曜・日曜も19時まで診療
- 初診相談は無料、オンライン相談にも対応
- ワイヤー矯正とマウスピース型矯正装置（インビザライン）の両方に対応
- 子どもの歯並びチェックは前歯が永久歯に生え変わる6〜9歳頃がおすすめ
- 同じビル内の一般歯科と連携し、虫歯・歯周病の治療もスムーズ
- 院内分割は最大12回まで無利息
- 部分矯正は2か月〜1年、全体矯正は1〜3年が目安
- 院長は日本3Dプリンティング矯正学会 2023年ベストプレゼンテーション賞を受賞

## 書かないこと

- 患者の体験談、ビフォーアフター写真（`05-compliance/guidelines.md`）
- 「地域No.1」「最新」「痛くない」などの比較優良・保証表現
- 割引・キャンペーンの多用（AIは事実情報を好む。販促色が強い本文は引用されにくい）

## 投稿以外で整えるGBP項目

- [ ] サービス欄に 治療メニューと料金（範囲）を登録
- [ ] 属性：オンライン診療（相談）あり、予約必須、バリアフリー等 該当するものを設定
- [ ] 診療時間・特別営業時間（祝日・年末年始）を最新に
- [ ] 説明文（750字）に `02-website/llms.txt.example` の冒頭と同じ事実を記載
- [ ] 写真：外観（駅からの目印）、受付、診療室、院長 を各1枚以上
- [ ] Q&A欄を `qa-seed.md` で整備
