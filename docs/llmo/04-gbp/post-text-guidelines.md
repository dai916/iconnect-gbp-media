# GBP「最新情報」投稿本文の書き方（AIに読まれる前提）

このリポジトリの `images/` に毎日置いている黒板画像は、Googleマップ上では人が見るが、
AIは **投稿の本文テキスト** を読む。画像の中の文字は読まれない。
本文側の書き方を次のルールに揃える。

**実装状況（2026-09-27）**: 非公開リポジトリ `iconnect-gbp` の `scripts/generate_gbp.py` に
`CLINIC_FACTS` として組み込み済み。毎日の生成で下の一覧から1つを日付で選び、本文に入っていなければ書き直させる。
投稿JSONには `fact` として記録される。

## 毎回入れる要素

1. **その日のテーマ**（画像と同じ内容を文章で。1〜3文）
2. **医院の事実を1つ**（下の一覧からローテーション。数字・地名・曜日は変えない）
3. **行動の一文**（例：「無料初診相談は『予約』ボタンから24時間ご予約いただけます」）
4. **リンクは本文に書かない**。GBP はボタン（CTA）で渡す。コラム連動は記事URL＋`?src=gbp`、院内情報は
   `https://iconnect-ortho.com/lp-consultation?src=gbp`（2026-09-04 から運用中。GA4 ではランディングページのクエリ文字列で区別する）

## 「医院の事実」ローテーション一覧（2026-09-26 院内確定）

- JR大森駅東口から徒歩1分（東京都品川区南大井）
- 土曜・日曜も19時まで診療（休診日は木曜・祝日）
- 初診相談は無料で、所要時間は約30分
- ワイヤー矯正とマウスピース型矯正装置の両方に対応
- 子どもの歯並びチェックは前歯が永久歯に生え変わる6〜9歳頃がおすすめ
- 同じビル2階の提携一般歯科と連携し、虫歯・歯周病の治療もご案内できる
- 院内分割は最大12回まで無利息
- 治療期間の目安は部分矯正で3か月〜1年、全体矯正で1〜2年
- WEB予約は24時間受付

一覧を変えるときは `iconnect-gbp/scripts/generate_gbp.py` の `CLINIC_FACTS` と、
`02-website/faq-draft.md` の記述を同時に更新する（本文・FAQ・JSON-LD の事実は常に一致させる）。

## 例

> 【矯正中の歯みがき】装置のまわりは汚れが残りやすいので、ワンタフトブラシを1本足すだけで磨き残しがぐっと減ります。
> 当院はJR大森駅東口から徒歩1分、土日も19時まで診療しています。
> 無料初診相談は「予約」ボタンから24時間ご予約いただけます。

## 書かないこと

- 患者の体験談、ビフォーアフター写真（`05-compliance/guidelines.md`）
- 「地域No.1」「最新」「痛くない」などの比較優良・保証表現、「認定医」（院長指定のNG語）
- 電話番号・URL・ハッシュタグ（GBP側の却下要因。`check_ng_gbp.py` が止める）
- 割引・キャンペーンの多用（AIは事実情報を好む。販促色が強い本文は引用されにくい）

## 投稿以外で整えるGBP項目

- [ ] サービス欄に 治療メニューと料金（範囲）を登録（2026-09-21 時点で13件・料金入りを確認済み）
- [ ] 属性：予約必須、バリアフリー等 該当するものを設定（オンライン診療は行っていないので付けない）
- [ ] 診療時間（10:30〜13:30／14:30〜19:00、木曜・祝日休診）・特別営業時間（年末年始）を最新に
- [ ] 説明文（750字）に `02-website/llms.txt.example` の冒頭と同じ事実を記載
- [ ] 写真：外観（駅からの目印）、受付、診療室、院長 を各1枚以上
- [ ] Q&A欄を `qa-seed.md` で整備
