# GBP Q&A欄に自院で投稿する質問と回答（種）

GBPのQ&A欄はオーナー自身が質問を投稿し回答できる。空欄のままにすると第三者の不正確な回答が残ることがある。
以下を院のアカウントで投稿し、回答を付ける。内容は `02-website/faq-draft.md` と一致させる。

| 質問 | 回答 |
|---|---|
| 初診相談は無料ですか？ | はい、無料です。オンライン相談にも対応しています。WEB予約は24時間受付です。 |
| 土日も診療していますか？ | 土曜・日曜も19時まで診療しています。休診日は【要確認】です。 |
| 大森駅からどのくらいですか？ | 東口から徒歩1分です。所在地は品川区南大井【要確認】。 |
| マウスピース矯正はできますか？ | マウスピース型矯正装置（インビザライン）とワイヤー矯正の両方に対応しています。 |
| 子どもの矯正は何歳から相談できますか？ | 前歯が永久歯に生え変わる6〜9歳頃のチェックをおすすめしています。 |
| 費用はどのくらいですか？ | 全体矯正【要確認：範囲】円（税込）、部分矯正【要確認】円です。院内分割は12回まで無利息です。詳細は料金表をご覧ください。 |
| 分割払いはできますか？ | 院内分割は最大12回まで無利息です。【要確認：ローン・カード】 |
| 虫歯の治療もできますか？ | 当院は矯正専門ですが、同じビル内の一般歯科と連携して対応します。 |
| 駐車場はありますか？ | 【要確認】 |
| 予約は必要ですか？ | 初診相談は予約制です。WEBまたはお電話【要確認】でご予約ください。 |
