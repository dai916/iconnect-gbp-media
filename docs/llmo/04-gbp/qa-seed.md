# GBP Q&A欄に自院で投稿する質問と回答（種）

GBPのQ&A欄はオーナー自身が質問を投稿し回答できる。空欄のままにすると第三者の不正確な回答が残ることがある。
以下を院のアカウントで投稿し、回答を付ける。内容は `02-website/faq-draft.md` と一致させる。

| 質問 | 回答 |
|---|---|
| 初診相談は無料ですか？ | はい、無料で約30分です。WEB予約は24時間受付、LINE・電話（050-3138-3592）でも予約できます。 |
| 土日も診療していますか？ | 土曜・日曜も19時まで診療しています。診療時間は10:30〜13:30／14:30〜19:00、休診日は木曜日と祝日です。 |
| 大森駅からどのくらいですか？ | 東口から徒歩1分です。所在地は〒140-0013 品川区南大井6丁目28-9 大成ビル1階です。 |
| マウスピース矯正はできますか？ | マウスピース型矯正装置（インビザライン）とワイヤー矯正の両方に対応しています。 |
| 子どもの矯正は何歳から相談できますか？ | 前歯が永久歯に生え変わる6〜9歳頃のチェックをおすすめしています。 |
| 費用はどのくらいですか？ | 全体矯正825,000〜1,430,000円（税込）、部分矯正275,000〜605,000円（税込）、小児矯正495,000円（税込）です。別途、検査・診断料33,000円（税込）と来院ごとの処置料5,500円（税込）。院内分割は12回まで無利息です。詳細は料金表をご覧ください。 |
| 分割払いはできますか？ | 院内分割は最大12回まで無利息です。デンタルローンとクレジットカード（VISA・Mastercard・JCB・AMEX・Diners）も使えます。 |
| 虫歯の治療もできますか？ | 当院は矯正専門ですが、同じビル2階の提携一般歯科と連携して対応します。 |
| 駐車場はありますか？ | 駐車場・駐輪場はありません。近隣のコインパーキングをご利用ください。 |
| 予約は必要ですか？ | 完全予約制です。WEB（24時間）・LINE・お電話（050-3138-3592）でご予約ください。 |
