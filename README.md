# iconnect-gbp-media

アイコネクト大森矯正歯科の Googleビジネスプロフィール「最新情報」投稿に添付する画像の公開置き場です。

- Google Business Profile API は画像を **公開URLから取得する** 仕様のため、投稿画像をここに置いて raw URL を渡しています。
- ここに入るのは **Googleマップ上で公開される黒板画像のみ** です。コード・認証情報・患者情報は一切含みません。
- 投稿の仕組み本体は非公開リポジトリ `iconnect-gbp` にあります。

## docs/llmo/

Claude などの生成AI経由の初診相談予約を増やすための **計画・テンプレート・計測ツール** を `docs/llmo/` に置いています。
公開されても問題ない内容のみで、認証情報・患者情報・計測結果の本文は含みません（詳細は `docs/llmo/README.md`）。
